---
title: Adagio
description: Build and run bioinformatics pipelines without writing code
---

Adagio lets you build and run bioinformatics pipelines through a visual interface and a portable CLI.

The same exported `.adg` pipeline file can be:

- built and edited in the browser
- inspected and run from the command line
- submitted to the shared pipeline catalog

## Start here

- New to Adagio: read [Introduction](/getting-started/introduction/).
- Want to build a pipeline: start with [Quick Start](/getting-started/quick-start/) and then [Connections and Semantic Types](/building/connections-and-types/).
- Want to run a downloaded pipeline: read [Running with the CLI](/running/cli/), [Runtime Configuration](/running/cli-config/), and [Cache Behavior](/running/cache/).
- Want to register a plugin or submit a pipeline: read [Registering and Submitting a Plugin](/contributing/submitting-a-plugin/) and [Submitting a Pipeline](/contributing/submitting-a-pipeline/).
